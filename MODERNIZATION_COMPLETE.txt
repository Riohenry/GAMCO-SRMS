================================================================================
                       COMMON QUESTIONS & ANSWERS
================================================================================

Q: How do I get started?
A: Read QUICK_START.md (5 minutes) or run:
   npm install && npm run dev

Q: What changed?
A: Migrated from Create React App to Next.js 16 with TypeScript and Tailwind CSS.
   See MODERNIZATION_GUIDE.md for details.

Q: How do I add a new page?
A: Create a folder in src/app/pages/ and add page.tsx.
   See QUICK_START.md for example.

Q: How do I convert a component to TypeScript?
A: Rename .js to .tsx and add types.
   See MODERNIZATION_GUIDE.md for examples.

Q: Where are the routes?
A: In src/app/ using Next.js file-based routing.
   See ROUTING_MIGRATION.md for mapping.

Q: Can I still use React Router?
A: No, Next.js App Router replaces React Router.
   Use next/link instead of react-router Link.

Q: How do I style components?
A: Use Tailwind CSS classes.
   See MODERNIZATION_GUIDE.md for migration reference.

Q: Where's the API?
A: Use src/app/api/ for API routes (Next.js feature).
   Or connect to backend service.

Q: How do I deploy?
A: Vercel is recommended (git push to deploy).
   See MODERNIZATION_SUMMARY.md for other options.

Q: What about the database?
A: Not included. Connect your own backend/database.
   Use NEXT_PUBLIC_API_URL environment variable.
